PRIVACY
POLICY

This portfolio site runs without contact forms, sign-up, personal accounts, analytics, advertising pixels or non-essential cookies.

Operator and purpose

The site operator is German Sergeevich Polkin. The site presents a professional portfolio, CV and contact options. Data enquiries: polkin-06@inbox.ru.

What is actually processed

The site does not ask visitors to submit personal data to the owner. Static files are hosted on GitHub Pages. The site owner does not keep its own access logs and does not receive visitor IP addresses through the site UI. When files are delivered, GitHub as infrastructure provider may process IP address, request time, URI and technical device data under its own terms and privacy policy. The site owner does not control retention or location of GitHub infrastructure logs.

Cookies, storage and analytics

The site does not set cookies, does not use localStorage or sessionStorage for tracking, and does not load web analytics, advertising, profiling or recommendation systems. Normal browser file caching is not a site-side user profile.

Local assets and outbound links

Fonts, images, video, CSS and JavaScript load from the site domain. During normal browsing there are no runtime requests to Google Fonts, YouTube, Cloudflare CDN, jsDelivr, external iframes or other third-party embeds. Telegram, VK, e-mail and the public DataLens view open only after a deliberate visitor action; further processing on the external resource follows that resource's policy.

Retention, security and rights

The site owner does not use technical data to make decisions about visitors, does not sell it and does not merge it with other databases. The connection is served over HTTPS; server-side measures and logs are defined by the GitHub Pages infrastructure. You can e-mail to request information about processing, correction or deletion of data relating to you within what the site owner actually controls.

Policy updates

A new edition is published before adding forms, analytics, cookies or any processing not described in this configuration.
